BLACK PEARL - an endless sea

Run:
  Double-click index.html to play (offline, progress saved in localStorage).
  For PWA install + offline caching, host the folder over https (GitHub Pages / Netlify)
  or run:  python3 -m http.server  -> http://localhost:8000

If you edit any file, bump CACHE in sw.js ("blackpearl-v1" -> "blackpearl-v2") so installed copies update.
